# Gmail Asset Hosting via GitHub Pages

To make your HTML email signature work flawlessly in Gmail, the images must be publicly accessible over the internet. 

Because you are using GitHub Pages, **hosting is handled automatically!**

## 1. What You Need to Do

Simply **commit and push** the current repository structure to GitHub. 

Once your repository is pushed to the `master` branch, GitHub Pages will automatically host your assets at:
`https://pratik-bhatia.github.io/email-signature/assets/[filename]`

### List of Automatically Hosted Assets:
1. `seamless-geometric-pattern.png`
2. `triangular-pattern-flipped.png`
3. `officeneed-logo.png`
4. `officeneed-wordmark.png`
5. `phone.png`
6. `email.png`
7. `website.png`
8. `linkedin.png`
9. `instagram.png`
10. `facebook.png`

## 2. Verify Your Hosting
After pushing your code to GitHub, wait a minute or two for GitHub Pages to deploy, then open this link in your browser to test:
[https://pratik-bhatia.github.io/email-signature/assets/officeneed-logo.png](https://pratik-bhatia.github.io/email-signature/assets/officeneed-logo.png)

If the logo loads in your browser, your GitHub Pages hosting is active and correctly configured!

---
**CRITICAL WARNING**: Do **NOT** attempt to copy the signature into Gmail before committing and pushing these assets to GitHub. If you do, the images will appear as broken icons to your recipients because the URLs won't be live yet.
